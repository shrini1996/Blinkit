Project Overview
This project analyzes Blinkit sales data using SQL, Python (EDA), and Power BI.
The goal was to generate insights on item sales, outlet performance, customer preferences, and trends, and then visualize them through an interactive dashboard.

Tools & Technologies
 • Data storage and querying: MySQL (advanced queries and window functions)
 • Dashboarding: Power BI (multi-page interactive reports)
 • Machine learning and analysis: Pandas, NumPy
 • Visualization: Matplotlib, Seaborn
 • Development environment: Jupyter Notebook.

Key Insights
Total Revenue: $32.19M
No. of Items: 8523
Average Rating: 3.34
Instant & Frozen Food boasts the highest profit margin (nearly 40%), while Fruits & Vegetables sits at the lower end (approx. 25%).
Tier 3 outlets and medium-sized stores are the primary revenue drivers
The App Push Notification campaign achieved a high Return on Ad Spend (ROAS).
Features
SQL scripts for data cleaning & KPI generation
EDA notebook with Python visualizations
Interactive Power BI dashboard with filters (Outlet Type, Size, Item Type, etc.)
Advice & Suggestions
Expand Tier 3 outlets since they generate maximum revenue.
Stock more low-fat products as demand is higher compared to regular-fat items
Focus on Medium sized outlets for new locations, as they contribute the largest share of sales, while Large outlets are currently underperforming in comparison.
Focus on improving Product Quality, as it is a major driver of negative feedback and lower average ratings (3.34).
Promote top-performing categories (Fruits, Snacks, Household) with targeted offers and marketing
